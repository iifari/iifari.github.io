# 포트폴리오 사이트

메인 랜딩 페이지와 포트폴리오 사이트 두 개로 구성된 정적 웹사이트입니다. 빌드 과정 없이 GitHub Pages에 바로 올릴 수 있습니다.

## 구조
```
index.html              메인 랜딩 페이지 (포트폴리오 목록)
assets/                 랜딩 페이지 스타일과 파비콘
kkh/                    김경환 적층가공센터 (숨김 처리됨)
battery-lab/            사랑의 배터리 연구대
.nojekyll               GitHub Pages가 파일을 그대로 서비스하도록 설정
```
각 포트폴리오 폴더는 자체 `index.html`, `css/`, `js/`, `assets/`를 가진 독립 사이트입니다.
모든 링크가 상대 경로라서 `사용자이름.github.io` 저장소든 일반 저장소든 그대로 동작합니다.

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 **모든 파일과 폴더**를 저장소 최상위에 업로드합니다 (`index.html`이 최상위에 있어야 합니다).
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
4. 주소:
   - 메인: `https://<사용자이름>.github.io/<저장소이름>/`
   - 사랑의 배터리 연구대: `.../battery-lab/`

## 꼭 수정할 내용
- 두 포트폴리오의 이메일, 전화번호, 주소 (`example.com`, `000-0000-0000`, `주소를 입력하세요`)
- `battery-lab/index.html`: 연구대 이름, 프로젝트 내용, 장비 목록은 예시 문구입니다. 실제 내용으로 바꿔주세요.
- `kkh/index.html`: 소재와 적층 두께는 예시입니다.
- 메인 `index.html`의 제목("포트폴리오")과 소개 문장

## 새 포트폴리오 추가하기
1. 기존 폴더 하나(예: `battery-lab/`)를 복사해 새 이름으로 바꾸고 내용을 수정합니다.
2. 메인 `index.html`에서 `<li class="folio">` 블록을 하나 복사해 링크(`href`), 로고, 이름, 설명을 바꿉니다.
   `--brand`(글자·버튼 색)와 `--tint`(로고 배경색)로 색을 지정할 수 있습니다.

## 이미지
`assets/images/`의 SVG 일러스트는 예시입니다. 실제 사진으로 바꾸려면 같은 폴더에 넣고 `<img src>`와 `alt` 설명을 수정하세요.

## 숨김 처리된 사이트 (kkh)
`kkh/` 폴더의 파일은 그대로 있지만 메인 페이지 목록에서 빠져 있고, 검색엔진에 노출되지 않도록 `noindex` 설정이 되어 있습니다.
다만 GitHub Pages는 비밀번호 보호를 지원하지 않으므로 `.../kkh/` 주소를 직접 아는 사람은 접속할 수 있습니다.
다시 보이게 하려면 메인 `index.html`에서 주석(`<!-- ... -->`)으로 감싼 김경환 적층가공센터 블록의 주석 표시를 지우고,
`kkh/index.html`의 `<meta name="robots" content="noindex, nofollow, noimageindex">` 줄을 삭제하세요.

## 이미지 검색 차단 (robots.txt)
`robots.txt`는 검색엔진에 이미지를 수집하지 말라고 요청하는 파일입니다. 각 페이지에도 `noimageindex` 설정이 들어 있습니다.
- `robots.txt`는 **도메인 최상위**에서만 읽힙니다. `<사용자이름>.github.io` 저장소에 올리면 적용되지만,
  일반 저장소(`<사용자이름>.github.io/<저장소이름>/`)에서는 적용되지 않습니다. 이 경우에도 페이지별 `noimageindex` 설정은 동작합니다.
- 검색엔진에 대한 요청일 뿐, 사이트 방문자가 이미지를 보거나 저장하는 것은 막지 못합니다.
